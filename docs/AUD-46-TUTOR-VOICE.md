# AUD-46 optional male Audli tutor

Settings offers **Audli — Original** (default) and **Audli — Male**. The approved ElevenLabs IDs are `yKYzqEa22xh5PdidhN70` and `OrG4D9yQsedssYoRLflr`. Existing and new profiles default to Original; Original retains the deployment's configured tutor default and existing cache identity. No new provider/model, voice purchase, migration or production configuration change is introduced.

The authenticated GET/PUT `/api/profile/tutor-voice` routes persist a strict `original | male` preference in the existing learner profile JSON. Writes lock and reread the current owner snapshot, changing only the tutor preference. Profile projection restores the optional field with an Original fallback for legacy snapshots. Onboarding writes, explicit onboarding restart, passage accent preferences and one-passage consent stay separate. Assessment completion preserves a preference saved concurrently on another device.

`TutorSpeech` snapshots the preference and audio settings once for a cue, shares the existing provider client, and never mutates shared settings. Onboarding, lesson/check-in/planner speech, exercise introductions, recognition retries/acknowledgments, summary/follow-up questions and deterministic terminal feedback use that snapshot for synthesis and cache identity. Original caches remain valid; a different ElevenLabs voice gets a different key. Changing Settings affects subsequent speech requests and does not pause existing playback. Existing character/byte/time limits, model, no-retry behavior and one Coral fallback remain unchanged. Passage synthesis is still delegated without the tutor override.

Preview is explicit and uses [ElevenLabs' existing recorded `preview_url`](https://elevenlabs.io/docs/api-reference/voices/get), never the text-to-speech endpoint. Metadata and audio use bounded GET requests with redirects disabled. Only the documented HTTPS public preview bucket is accepted, and provider credentials are never sent to that bucket. The recording is decoded, metadata-stripped, capped at 12 seconds and cached by owner/voice ID. The existing generated-audio sanitizer retains its 150-second default for every existing caller. Missing/unavailable/invalid previews return a safe error with no synthesis fallback or preference change. No preview is requested automatically when opening Settings or saving a choice.

The radio group, explicit Save and labeled Preview controls support keyboard/screen-reader access. Recorded audio uses native controls. Async operations are bound to account/component lifetime; logout/navigation cancels work and releases preview audio/object URLs.
