# AUD-20 release readiness — global scope

The single-account/cohort pilot proposal is superseded by the full-platform
rollout to **all authenticated Audli learners**, existing and newly registered.
No account allowlist or account-specific eligibility restriction is proposed.

See [the global release-readiness plan](AUD-20-GLOBAL-RELEASE-READINESS.md) for
human-review instructions, the disabled global configuration proposal, verification
matrix, usage/spending controls, production compatibility evidence, deployment
and no-database-change rollback. Historical review HTML/ZIP filenames are kept so
the existing twelve audio samples and review links continue to work.

Status remains **not ready**: mandatory human CSV review and other documented
release gates are pending. AUD-20 stays In Progress until deployed and verified
in production for the intended full authenticated population. No production
configuration, feature flag or deployment has been changed.
